# Edurate

Edurate is an Android application designed to enhance the learning experience. This project leverages modern Android development practices and libraries.

## Features

- User authentication and profile management
- Teacher rating and feedback system

## Tech Stack

- **Language:** JavaScript
- **Framework:** React Native, Expo Go

## Getting Started

1. Clone the repository:
    ```
    git clone https://github.com/Jovellmiranda14/Edurate-mobile.git
    ```
2. Open in Visual Studio Code
    ```
    cd Edurate-mobile
    code .
    ```
3. Install dependencies
    ```
    npm install
    ```
4. Start the development server 
    ```
    npm start
    ```

## Folder Structure

- `components/` - Reusable UI components
- `screens/` - Screens and UI components
- `App.js` - Entry point of the app
